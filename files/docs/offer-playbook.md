## The Funnel (Brunson VSL Structure)

```

        ↓

  - Hook: "You don't need to hire anyone"
  - Problem: Solopreneurs drowning in execution
  - Solution: AI system demo (show the Notion dashboard)
  - Proof: Your own results / before-after
  - CTA: Get it for $47
        ↓
Order Page
  + Order Bump: $17 — "The 50 Best AI Prompts for Solopreneurs"
        ↓
OTO 1: $97 — Custom prompt library for your niche
        ↓
OTO 2: $297 — 1:1 implementation call
        ↓
Email sequence (5 emails, drive to OTO 2 if not bought)
```

**Revenue math (Sam's model):**
- 6 sales/day at $47 = $282/day base
- 30% order bump take rate = +$5/avg order
- 20% OTO1 take rate = +$19/avg order
- 10% OTO2 take rate = +$30/avg order
- **Blended avg order value: ~$101**
- 6 sales/day × $101 = $606/day = **~$18,000/month**
- Ad spend to drive 6 sales at 5% CVR = ~$60-80/day
- **Net: ~$15,000/month at scale**

## Build Plan (AI does the heavy lifting)

**Day 1-2: Build the product**
- Use Claude/ChatGPT to generate the full Notion AI Operator system
- 10 workflows: email triage, content repurposing, research, outreach, invoicing, etc.
- Prompt library: 50 battle-tested prompts per workflow
- Export as Notion template + PDF

**Day 3: Build the funnel**
- Landing page: Carrd or ClickFunnels (Brunson's own tool)
- VSL: Screen record walking through the Notion dashboard. No face needed.
- Copy: Use Sam's formula — Problem → Agitate → Solution → Proof → CTA

**Day 4: Launch ads**
- Facebook/Instagram
- Budget: $20/day to start
- Creative: Screen recording of the product in action
- Hook options to test:
  - "I replaced my VA with this Notion system"
  - "This AI toolkit saves me 20 hours a week"
  - "Stop hiring people. Build this instead."

**Day 5+: Let data decide**
- Kill ads with CTR under 1% after $50 spent
- Double budget every 3 days if CAC under $25
- First 10 buyers: DM them, get testimonials, feed back into ads

## Validation Shortcut (Before spending on ads)

Sam's rule: **sell before you build.**

Post in 3 communities before building anything:
- r/Entrepreneur
- r/ChatGPT
- Relevant Facebook groups (solopreneurs, agency owners)

Post: "Would you pay $47 for a Notion system that automates 10 recurring tasks using AI? DM me if interested."

If 5+ people say yes in 48 hours — build it. If not — adjust the angle.
